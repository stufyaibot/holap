# Holap 🌴

Static holiday planner. No server, no database, no dependencies. Just one HTML file.

## What it does

- Search any destination (Bali, Bangkok, Paris, etc.)
- Shows cheapest hotels, flights/trains/buses, and activities
- Calculates the total cheapest combo automatically
- Fully responsive, works offline

## Deploy anywhere free

| Platform | How |
|----------|-----|
| GitHub Pages | Push to `gh-pages` branch |
| Vercel | `npx vercel --prod` |
| Netlify | Drag and drop `index.html` |
| Cloudflare Pages | Connect repo |

All give you a free HTTPS URL with zero cost.

## Local

```bash
open index.html
```

That's it. No `npm install`, no build step.
